# 面向数据分析的通用 AI 工作台：MVP 产品说明

更新日期：2026-11-06。本文记录已确认的产品需求；实现方案与实测证据见 [技术文档](technical-design.md)，阶段交付见 [开发与验收计划](development-plan.md)。本期交付目标是用户本机可用的 macOS 应用，不以公开发布、签名公证或 Intel 支持作为完成条件。

## 1. 产品目标

产品定位是**支持数据分析工作的通用 AI 工作台**，让不懂 SQL/Python 的用户通过自然语言使用 Agent，看到执行过程、图表和 Markdown 报告，并能继续追问、调整任务和保留结果。

工作台保证其功能与流程正常、状态如实呈现、体验友好；不保证 Agent 编写的代码、分析方法或结论正确。Agent 负责理解需求、处理数据、执行分析及解释问题，工作台不内置分析正确性判定器。

用户选择一个或多个 CSV，提出例如“分析最近三个月各地区销售变化，找出下降最明显的地区”的问题。Agent 自行决定如何读取、清洗、关联、计算和绘图；应用不要求用户配置 SQL、Python 或 join 向导。内置 skill 引导 Agent 在遇到影响结论的业务歧义时简短澄清；是否识别并妥善处理属于 Agent 效果评测。

本期支持把多个 CSV 路径交给 Agent 使用。是否关联、使用哪些键以及怎样处理重复键，由 Agent 结合用户目标决定；关联导致的金额放大属于 Agent 分析质量问题，工作台不检测或裁定。

执行过程展示：一轮用户提问后的 thinking 与 tool 统一进入可折叠区域。运行时展开摘要，结束后自动收起；正文回答留在区域外。用户可手动查看思考、调用参数与结果，折叠标题保留失败提示，审批和补充信息始终单独展示。

每轮结束后在回答下方显示用量入口，点击查看 token 总量、实际提供方/模型、对话模型调用次数、缓存输入与输出明细。推理 token 属于输出子集；用量按本轮所有请求累计，包含重复发送的上下文及已记录的重试、自动压缩用量。缺失统计、中断或旧历史无法确认完整性时显示“已记录用量”，不将未知显示为确定的零消耗。用量随原生会话记录保存，重启可恢复。

## 2. 数据输入

- 通过拖拽或文件选择添加 CSV，显示文件名、原始路径和文件大小。同名文件通过路径区分。
- **直接引用原文件路径，不复制到 workspace，不做 CSV 版本管理。** 文件仍由用户管理，删除会话不得删除原始 CSV。
- 单文件不超过 **100,000,000 bytes**；一次分析选用的全部 CSV 合计也不超过该值。不能把每个文件都合规当作总量合规。
- 工作台不解析 CSV，不提供基于解析的表格预览、编码/分隔符选择或数据清洗；允许用户按需查看 CSV 的只读原始文本（有界读取）。Agent 通过通用工具自行读取、识别和处理；无法解决时由 Agent 向用户说明，工作台展示其消息和工具错误。
- 应用不监测、不补救用户在外部修改、替换或移动文件；实际读取失败时正常报告错误。不提供冻结数据、原始数据快照或外部文件变更追踪功能。
- 运行期间可以添加其他输入文件。需要当前任务使用新文件时，以新的 steer 消息明确告诉 Agent；添加附件本身不代表修改已提交指令。
- 保留生成的脚本与结果便于检查，但原始 CSV 变化后不承诺复算得到相同结果。

本地计算不代表完全离线。使用远程模型时，用户消息、列名、必要样本、工具结果和聚合结果可能发送给模型提供方；在首次使用时清楚说明。附件提交只提供路径与文件元数据，不自动读取完整文件放入上下文；Agent 的通用读取工具限制单次返回量。

## 3. 分析与结果

| 能力       | 产品要求                                                                                             |
| ---------- | ---------------------------------------------------------------------------------------------------- |
| 分析场景   | 趋势、分组比较、排名、占比、分布和多表关联等由 Agent 完成，作为效果评测场景                          |
| 数据理解   | 展示 Agent 返回的数据描述、样本和澄清问题；工作台不自行解析、推断字段或统计缺失值                    |
| 图表       | 展示 Agent 生成的静态图表；提供内置中文字体，不判断绘图数据或图意正确性                              |
| 报告       | 渲染 Agent 生成的 Markdown；内置 skill 建议说明结论、口径、数据质量和局限，内容质量由 Judge 评测     |
| 本地结果   | 管理和展示 Agent 实际生成的文件；可打开目录、复制 Markdown、导出报告及相关图片                       |
| 追问       | 改时间范围、维度、排序、图表或口径；同一会话共用工作区，可更新同名结果；需要保留两份时另命名或先导出 |
| 状态与错误 | 区分执行完成/失败/取消/中断、文件未生成及文件无法展示；不把这些状态表达成“分析结果正确”              |

分析方法、统计口径、缺失值、基期零、事实与推断的区分等由 Agent 负责。可以通过内置 skill 指导，通过 Judge 评测效果，但不成为工作台的业务校验逻辑。

工作台仅检查展示和访问所需的文件条件，例如文件是否存在、非空、路径是否允许访问、图片是否能解码。“执行完成”表示本次执行已收束，“已生成报告”表示对应文件存在且非空，均不代表内容准确。自由聊天不强制生成报告；指定文件名可以作为测试用例的交付约定。

## 4. 会话、并发与插话

- 多轮聊天持久化，重启后可浏览历史、工具过程、结果，并继续对话；提供新建、标题、搜索、归档与删除。
- “新会话”只进入可恢复的首页草稿，第一次有效发送被接收后才创建正式会话；选文件和回首页不产生空会话。
- 每个会话拥有独立 workspace。默认自动创建；首次执行前可指定保存位置，应用在所选父目录下建立该会话的独立子目录。
- **不同会话最多同时执行 2 个任务，更多任务排队；同一会话内部只有一个持续执行。** 切换会话不终止任务；停止 A 不影响 B。
- **调整当前任务（steer）**：在当前工具批次完成后生效，不承诺立即改写正在运行的 Python。
- **排队继续（follow-up）**：当前分析准备结束时按顺序处理；队列清楚显示是否尚未发送。
- **停止**：停止该会话的模型/工具执行及审批等待，未消费输入保留为未发送；已经完成的文件操作不会自动回滚。
- 关闭 macOS 窗口后继续运行；待审批任务保持暂停，重开窗口后可处理。**Cmd+Q 停止全部任务、保存状态并退出。**
- 崩溃或重启后不自动重跑未完成任务、未知是否消费的输入或未批准操作；显示中断状态，由用户决定继续。

会话列表及路径等状态存入全局应用目录，会话内容保留 pi 原生 session tree JSONL。用户无需管理这些格式，但可以打开结果目录。

```text
~/.data_agent/
  state.sqlite
  sessions/{session_id}.jsonl
  workspace/{session_id}/      # 默认产物目录，可为会话选择其他保存位置
  logs/
```

同一会话的普通提问、插话、后续提问共用一个工作区，产物直接保存于其中，不自动建立 run/version 目录或保留每轮副本。旧版已生成的历史目录保留可读。

原始 CSV 位于用户选择的原路径，不属于上述目录的托管输入。删除会话可以选择是否清理应用产物，不能删除外部 CSV、自选父目录或未登记的用户文件。

## 5. 模型、工具与 Skills

- 提供模型选择与 BYOK，开放 pi 内置的 API-key 模型配置；只有完成产品测试的组合标为已验证，其他组合标为未验证兼容性。
- 本期真实集成验收固定 **DeepSeek-V41-Flash**。支持对内置 provider 设置 API Base URL（沿用其协议与模型清单）；新增自定义 provider/model、OAuth 订阅登录不纳入首版。
- 同一会话的模型切换在两次执行之间生效，不改变正在运行的任务配置。
- 展示模型实际返回的正文、thinking、tool call、tool result；不支持或未返回 thinking 时不伪造。
- 工具保持通用：读取、写入、编辑、目录浏览、搜索、命令执行和用户澄清。分析方法放在内置 skills，不增加绑定 CSV/pandas 的专用 Agent 工具。
- 首版只加载随应用发布的可信 skills；不加载用户自行添加的 skills/extensions。
- Python 和常用分析库随应用提供；不要求用户安装 Python/pip/Homebrew。缺少额外库时说明限制，**不让 Agent 自动安装依赖或修改内置运行时**。

## 6. 审批与安全边界

采用命令/脚本规则、路径检查和人工审批，不使用产品执行沙箱。

| 操作                                           | 默认行为                                                          |
| ---------------------------------------------- | ----------------------------------------------------------------- |
| 工作区和普通外部文件读取                       | 允许；敏感路径拒绝                                                |
| 常规工作区内写入                               | 允许；保护原始输入、应用控制文件和已发布结果                      |
| 检测到工作区外写入/删除                        | 暂停，请求允许一次或拒绝                                          |
| 检测到工具执行联网                             | 暂停，请求允许一次或拒绝；配置并发起的模型 API 调用不重复弹此审批 |
| 明确危险命令、敏感路径、修改控制文件、安装依赖 | 拒绝                                                              |

审批展示对应会话、操作、路径或网络目标及原因；参数或代码变更使旧批准失效。批准只授权当前操作，不形成永久放行。取消、应用退出和崩溃后旧批准不能再次使用；仅关闭窗口不会撤销仍在等待的审批。

CSV 单元格、文件正文和工具结果里的“指令”是资料内容，不是用户授权，不能要求工具绕过审批或读取敏感文件。

这些措施用于减少可识别的误操作；**不承诺任意 Python、动态代码和原生库的所有文件或网络操作都能被静态检测**。应用不会将其描述为系统级隔离。

## 7. 界面

保留参考图的布局，去掉品牌标识；默认深色，右上角支持深色/浅色切换并在重启后保留选择：左侧会话列表和设置，中间聊天与输入框，右侧可折叠的数据/图表/报告面板。输入框 Enter 发送、Shift+Enter 换行，兼容 ⌘ Enter；空格与输入法候选确认不触发发送。

- 空态引导添加 CSV 和描述分析目标，显示产物保存位置。
- 输入框只展示待提交附件，接收后进入消息记录与会话资料区；解除资料关联不删除原文件。文件附件展示名称及路径；不使用“已上传云端”措辞。
- 正文流式显示，thinking/工具过程可展开；长日志截断后可查看完整内容。
- 输入区提供模型、可用的思考强度、steer/follow-up 和停止。
- 并发/排队/待审批状态可见；审批必须明确属于哪个会话。
- 报告内直接显示图片，支持复制和导出；不要求用户阅读代码才能使用。

## 8. MVP 完成范围

首版本机目标为 macOS 15.7.4、Apple M4、arm64、24 GiB 内存。实际 `.app` 必须通过真实 Electron/CDP、真实 DeepSeek、内置 Python、多文件任务交付、并发、停止、审批和恢复的流程验收；不能用纯网页预览或单元测试代替。

验证分为两条线：**程序/规则化验证**回归工作台逻辑和任务交付（例如指定 `report.md` 存在且非空），不验证分析结果准确性；**LLM-as-a-judge**独立评测 Agent 效果，当前由开发协作中的 AI Agent 担任 Judge。Judge 不是产品运行时组件，不是报告展示前的审核步骤；其评价不等于正确性保证。两类结果分别记录。

本期不包含公开发布/签名公证门禁、Windows/Linux、Intel 验证、Excel/数据库连接、云同步、账号体系、定时任务、Notebook、交互 BI、PDF/PPT 导出、第三方 skills 市场和额外依赖安装。

具体测试命令、证据和完成标准统一放在 [开发与验收计划](development-plan.md)。当前技术验证与正式产品验收的区别、已通过范围及实际限制统一放在 [技术文档](technical-design.md)。
