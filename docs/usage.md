# 本机使用

本期应用面向已验证的 macOS arm64 环境。打开 `release/mac-arm64/Data Agent.app`；可以把整个 `.app` 移到其他本机目录，必须保留包内资源。无需安装 Python、Node 或分析库。构建和验收方法见 [README](../README.md)，当前验收状态见 [实施进度](implementation-status.md)。

## 第一次分析

1. 打开左下角“设置”，选择 DeepSeek 或 OpenRouter，先填写可选 Base URL，再填 API key 并保存；列表获取后选择模型。首版完整真实验收使用 DeepSeek-V41-Flash；其他兼容模型标明未验证兼容性。应用不会自动读取开发者的 shell 配置。
2. 点击“新会话”进入首页草稿；可在输入区选择工作区父目录。首次发送被接收后才创建会话，回首页和选择文件不会创建空会话。默认会话目录位于 `~/.data_agent/workspace/`。
3. 点击输入区加号选择 CSV，也可拖入文件。待发送文件显示在输入框；接收后保留在对应消息中。多个文件可以一起分析，单文件与所选文件总量均不超过 100,000,000 bytes。这里只登记原路径，不复制、解析或上传整份文件。
4. 输入需求，例如“比较这几个月各地区的销售变化，分别按金额和比例找出下降最大的地区，生成 report.md 和中文图表”。点击发送或按 `Enter`；`Shift+Enter` 换行，空格正常输入。兼容 `⌘ Enter`，中文输入法确认候选词时不会发送。
5. 聊天区显示正文、思考和工具调用；右侧工作区展示实际目录中的文件，包括代码、CSV 原始文本、Markdown 和 PNG。外部附件仍保留在原路径，不出现在工作区目录。通过右上角面板按钮打开预览，可拖动分隔线调宽、展开专注阅读、复制当前内容、另存当前文件或在 Finder 中定位。

同一轮的思考与工具调用汇总在一个“执行过程”区域。运行时默认展开，各项用一行摘要展示，可继续展开思考全文、工具参数、结果与日志；轮次完成、失败或停止后自动收起，正文回答仍在外面。折叠标题保留工具调用次数和失败次数。可随时手动展开，查看过程不会强制跳到最新消息；审批和补充信息卡片不放进折叠区。重新打开会话时，历史过程默认收起。

每轮结束后，回答下方的“本轮用量”可点击查看精确 token 数、实际模型、调用次数、缓存命中率和输入/输出明细。支持键盘 Enter 打开、Escape 关闭并返回入口；深浅主题一致。缓存命中率按所有调用的输入加权计算，推理 token 已包含在输出中；“其中已报告推理”仅展示已返回的正数明细。停止、断网或旧历史缺少完整统计时显示“已记录用量”；未获取用量不代表零消耗。原始用量与轮次边界保存在会话 JSONL，重启可查看。

模型可能通过工具读取文件内容，必要样本、结果和对话会发送给所选模型提供方。报告内容由 Agent 生成，“执行完成”不代表分析正确。

## 外观与文件预览

右上角太阳/月亮按钮切换浅色与深色模式，默认深色，重启后保留选择。主题覆盖聊天、设置、审批和文件预览；图片保持原始颜色。

右侧“文件”按目录列出当前 workspace 中的实际文件，包括手动放入的文件。展开目录后读取内容；可刷新、显示隐藏文件，单目录超过 2,000 条时提示截断并可在 Finder 查看。点击文件进入预览，不自动选择报告。Markdown 可切换阅读视图/源码，代码提供高亮与行号，CSV/TSV/TXT/日志按原始文本展示，不解析表格。JSON/YAML 等文本也可查看，PNG 支持缩放。符号链接和特殊文件不跟随，不支持项明确提示。

普通文本预览最多展示开头 128 KiB / 2,000 行，截断会明确提示；“复制当前内容”仅复制显示的文本。超过 32,768 字符时停用语法高亮。文本预览支持 UTF-8，其他编码、二进制或不支持的格式说明原因，可通过预览工具栏的文件夹按钮在 Finder 中定位。读取的是当前文件，不维护版本。Markdown 超过 2 MiB 时使用有界文本预览；PNG 上限 25 MiB / 4,000 万像素。“另存文件”只复制当前一个文件（最多 500 MiB），不会连同报告引用的图片打包；完整目录可通过 Finder 复制。

面板和聊天独立滚动；宽表格/代码在内容内横向滚动。阅读历史时新消息不会抢位置，使用底部向下箭头回到最新。新产物不强制打开面板或切换你正在查看的文件。图标悬停或键盘聚焦可查看操作提示。

## 继续和并发

- 普通追问、插话和后续提问都使用同一个会话目录，不再创建每轮子目录。同名文件可以更新，预览在任务结束后刷新；需要保留前一份结果时，先导出或要求 Agent 另存文件名。旧目录若位于 workspace 内，可作为普通目录浏览；没有版本选择器。
- 执行期间，“插话”在当前工具批次完成后调整任务；“后续提问”等待当前任务准备结束后消费。两者都不会立即中断正在执行的 Python。
- 不同会话最多同时运行两个任务，其余排队。侧栏显示运行、排队和待审批状态；切换会话不停止任务。
- 添加文件不会自动改变已经提交的指令。要在当前任务使用新文件，通过插话明确说明文件路径和目的。
- “停止”只停止当前会话。未消费输入保留为未发送，可放回输入框后再次提交；已写入的文件不会回滚。

关闭窗口后任务继续，待审批保持暂停；重新打开应用可继续查看。`⌘ Q` 停止全部任务并退出。异常退出后的任务显示中断，不自动重跑。

## 审批、文件和限制

检测到工作区外写入/删除或工具联网时，会显示具体操作和一次性审批。普通外部读取默认允许，敏感路径、明确危险命令和依赖安装拒绝。审批机制是规则检测，不是执行沙箱；无法保证识别任意动态代码的全部行为。

Python 内置 pandas、NumPy、Matplotlib、Seaborn、Pillow 等固定库及中文字体。额外安装不在首版范围。任务最多 20 次模型请求、10 分钟活跃执行时间，单工具最多 180 秒；等待用户审批或澄清不计活跃时间。这些限制由程序阻断，不向模型逐次注入剩余次数提示。触及限制会明确停止并保留已有产物，可据此缩小任务后继续。

会话标题、路径等保存在 `~/.data_agent/state.sqlite`，聊天使用 `sessions/{session_id}.jsonl`。原 CSV 始终在原路径，移动或删除后需要重新添加。删除会话只清理对话和应用内部日志，workspace、原 CSV 以及所有手动文件始终保留。确认框显示目录，可先在 Finder 打开；删除后侧栏不再保留入口，需要删除文件时自行操作 Finder。

遇到工具错误，可展开工具卡查看输出或打开完整日志。报告不存在、为空或图片损坏时，界面如实显示文件状态；Agent 可解释或继续修复，工作台不判断业务结果正确性。

## 配置模型连接

设置按“提供方 → Base URL → API key → 模型”排列，只支持 DeepSeek 和 OpenRouter。“默认模型”是可搜索的下拉选择器：点击当前模型后，在弹出列表中按名称或 ID 搜索；上下方向键移动、Enter 确认、Escape 关闭并返回入口。搜索只过滤当前提供方的已获取列表，不发起网络请求；无匹配时保留原选择。选择模型或思考级别后自动保存，仅影响之后提交的任务。思考级别随模型变化；同名级别不代表相同 token 数，已保存的个人选择优先于推荐值。

“提供方连接”可以独立管理各提供方，不会切换默认模型。已保存的 Key 显示固定遮罩；点击“更换 Key”编辑，显示/隐藏仅针对新输入。修改 Base URL 或恢复默认地址时需要重新输入对应 Key，点击“保存凭证”一起保存，并获取模型列表。若获取失败，可点击“获取模型列表”重试；修改连接会清除旧列表。列表只展示服务返回且当前 SDK 识别的聊天/工具模型；更新时间显示在列表上方，应用重启可继续使用缓存列表。未保存草稿在切换提供方、模型或关闭设置时保留，但退出应用后不保留。取消编辑不会改动已保存连接。

Base URL 使用 HTTPS，本机服务可用 HTTP；填写 API 根地址而非完整 `/chat/completions` 路径。它保留所选内置提供方的协议与模型名，不能借此添加未知模型或任意协议的服务。

获取列表并选择默认模型后，点击“测试模型连接”。测试向保存的地址发送一条短请求，可能产生少量费用，不发送会话或文件。收到有效模型内容后立即结束探测，不等待完整回复；仅收到 HTTP 响应或空帧不算通过。无响应、服务已连接但未产出内容、服务繁忙会分别提示。403 表示地区或模型权限受限，不一定是 Key 错误；获取公开列表不等于 Key 或每个模型可用。测试通过不代表全部模型能力已验证。应用诊断中的“检查本地引擎”只检查本地进程，不检查 Key。移除凭证需确认，同提供方所有模型的新任务将不可用；运行中和排队中的任务仍保持提交时的配置。

## Agent 配置与版本

打开“设置 → Agent 配置”，可以编辑行为系统提示词、启停工具和内置 Skills。修改后点击“保存配置”，实际变更生成新版本，仅用于之后创建的新会话。切换设置分类会保留草稿；关闭设置时可以继续编辑、放弃修改或保存并关闭。恢复默认提示词与撤销修改不会立即保存。

工具开关控制模型可调用的接口，不替代文件/网络权限策略。例如保留 bash 时，关闭 write 也不等于禁止所有写文件行为。开启内置 skill 需要 read；冲突时可明确启用 read 或关闭 skill。全部工具和 skills 都关闭时只进行对话，不能处理本地文件。

设置页显示“版本 vN · 用于新会话”。会话顶部“会话操作 → Agent 配置”展示本会话固定的版本，以及提示词、工具和 skill 正文；即使默认值已更新，此会话仍保持原配置。模型与思考级别仍可在两次执行之间修改，它们与这里的会话固定配置是不同设置。

展开“查看完整系统提示词预览”，可查看 SDK 实际组装的文本，包含 Skills 索引和工作目录的类 XML 标签。这里使用当前草稿，工作目录暂用占位路径；预览不调用模型、不保存配置。会话详情的“系统提示词”展示原生历史中已记录的内容，尚未生成记录时会明确标为按绑定配置组装。工具参数通过模型 API 独立发送，不包含在这段文本中。

“使用最新配置新建会话”只打开首页草稿，不创建空会话、不复制旧聊天或重新执行任务。历史配置可核对时显示“历史配置”；缺少足够信息或绑定损坏时显示“配置待确认”，原内容保留。此时需恢复匹配的配置/历史备份，或使用最新配置新建会话，应用不会悄悄采用新的默认值。

## 存储升级

新版自动把元数据升级为六张应用表，升级前在 ~/.data_agent/backups/ 创建包含 WAL 的一致性备份。不会搬移、改写或删除工作区文件及原生会话历史；旧完整日志文件保留原位，但不提供旧索引查询。升级后不要使用旧应用打开新数据库。若需要回退，应保存完整数据再使用匹配版本与升级前备份；仅恢复 SQLite 不会撤销后续 JSONL/文件改动。
