# 本机使用

本期应用面向已验证的 macOS arm64 环境。打开 `release/mac-arm64/Data Agent.app`；可以把整个 `.app` 移到其他本机目录，必须保留包内资源。无需安装 Python、Node 或分析库。构建和验收方法见 [README](../README.md)，当前验收状态见 [实施进度](implementation-status.md)。

## 第一次分析

1. 打开左下角“设置”，选择提供方和模型，填写自己的 API key 并保存。首版完整真实验收使用 DeepSeek-V41-Flash；其他 pi 内置模型标明未验证兼容性。应用不会自动读取开发者的 shell 配置。
2. 点击“新会话”，或通过工作区旁的下拉按钮在指定父目录创建新会话。默认会话目录位于 `~/.data_agent/workspace/`。
3. 点击输入区加号选择 CSV，也可拖入文件。多个文件可以一起分析，单文件与所选文件总量均不超过 100,000,000 bytes。这里只登记原路径，不复制、解析或上传整份文件。
4. 输入需求，例如“比较这几个月各地区的销售变化，分别按金额和比例找出下降最大的地区，生成 report.md 和中文图表”。点击发送或按 `⌘ Enter`。
5. 聊天区显示正文、思考和工具调用；右侧“报告”展示实际生成的 Markdown 和 PNG。可以展开面板阅读、复制 Markdown、导出这一版或打开工作区查看脚本。

模型可能通过工具读取文件内容，必要样本、结果和对话会发送给所选模型提供方。报告内容由 Agent 生成，“执行完成”不代表分析正确。

## 继续和并发

- 普通追问创建新一轮输出，旧报告保留；右侧版本选择器可查看和导出以前的结果。
- 执行期间，“插话”在当前工具批次完成后调整任务；“后续提问”等待当前任务准备结束后消费。两者都不会立即中断正在执行的 Python。
- 不同会话最多同时运行两个任务，其余排队。侧栏显示运行、排队和待审批状态；切换会话不停止任务。
- 添加文件不会自动改变已经提交的指令。要在当前任务使用新文件，通过插话明确说明文件路径和目的。
- “停止”只停止当前会话。未消费输入保留为未发送，可放回输入框后再次提交；已写入的文件不会回滚。

关闭窗口后任务继续，待审批保持暂停；重新打开应用可继续查看。`⌘ Q` 停止全部任务并退出。异常退出后的任务显示中断，不自动重跑。

## 审批、文件和限制

检测到工作区外写入/删除或工具联网时，会显示具体操作和一次性审批。普通外部读取默认允许，敏感路径、明确危险命令和依赖安装拒绝。审批机制是规则检测，不是执行沙箱；无法保证识别任意动态代码的全部行为。

Python 内置 pandas、NumPy、Matplotlib、Seaborn、Pillow 等固定库及中文字体。额外安装不在首版范围。任务最多 20 次模型请求、10 分钟活跃执行时间，单工具最多 180 秒；等待用户审批或澄清不计活跃时间。触及限制会明确停止并保留已有产物，可据此缩小任务后继续。

会话标题、路径等保存在 `~/.data_agent/state.sqlite`，聊天使用 `sessions/{session_id}.jsonl`。原 CSV 始终在原路径，移动或删除后需要重新添加。删除会话时可选择清理登记产物；应用保留原 CSV、外部父目录和未登记的手工文件。

遇到工具错误，可展开工具卡查看输出或打开完整日志。报告不存在、为空或图片损坏时，界面如实显示文件状态；Agent 可解释或继续修复，工作台不判断业务结果正确性。
