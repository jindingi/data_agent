覆盖范围与清理口径

  • 快照共 — 行、12 列；按 show_id 去重后 — 部作品（重复 ID — 条已移除）。
  • 内容类型：电影 — 部、剧集 — 部。
  • 发行年份跨度 —；上架日期跨度 —。
  • 国家/地区为逗号分隔多值字段，拆分后去空去重；缺失 — 条记为“未标注”。
  • 题材同样多值拆分；源数据 — 个标签中 Movies／TV Shows 只是格式标签，已从题材维度排除，仅含格式标签的 — 条记为“未标注”。
  • 上架日期按 “September 25, 2021” 解析为日期；缺失 — 条不参与上架趋势。
  • 分级缺失 — 条记为“未标注”；其中 — 条原始记录的时长被误写入分级列，已回填为电影分钟数。
  • 电影按分钟、剧集按季数分别解析，两类单位不合并统计。

口径与解读边界

  • 去重键：show_id；作品总数、占比、分布与列表共用同一筛选结果集（含片名搜索）。
  • 多值全计数：国家/地区与题材的“出现次数”合计大于作品数；占比分母始终是当前筛选的作品总数，因此单项占比之和可超过 100%。
  • 未标注：国家/地区、题材、分级、上架日期的缺失都保留为可见类别，不与“其他”合并。
  • 发行年份 ≠ 上架日期：发行年份是作品首映/发行年，上架日期是加入 Netflix 目录的日期，两者相差数十年也属正常。
  • 内容分级（TV-MA、PG-13 等）是内容适龄标签，不是用户评分；快照也不含评分、观看量。
  • 上架趋势：2021 年截至 —，仅为部分年度；数据集无下架记录，新增上架数不能等同于片库净增长。
  • 快照边界：仅反映该 Kaggle 快照（约 2008–2021 年上架记录），不代表 Netflix 当前或历史完整片库；国家/地区为自由文本，存在合拍与命名差异。
